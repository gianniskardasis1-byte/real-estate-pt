About my project

The Gio Project is a backend-focused application that highlights Gio's work through a simple, presentation-ready platform. The goal is to give visitors a clear introduction to the project while keeping the foundation lightweight and easy to extend.

Purpose

Present the project in a clear way and show how the platform can grow from an API foundation into a complete product experience.

Focus

Keep the current experience simple, explain the product vision, and make the project easier to share during demos or portfolio presentations.

Next steps

Build on the existing user and residency flows with richer browsing, management, and frontend features over time.

Current platform capabilities

  • User registration endpoint under /api/user/register.
  • Residency creation endpoint under /api/residency/create.
  • Express-based backend with CORS, cookies, and environment support.
  • A dedicated presentation page available at the root URL.

Technology snapshot

Express

Handles routing, middleware, and server delivery.

Prisma

Used for data access in the existing controllers.

Static delivery

Serves this presentation directly from the same Node server.
